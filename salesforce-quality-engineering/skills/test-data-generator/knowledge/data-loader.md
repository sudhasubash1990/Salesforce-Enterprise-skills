# Data Loader

## Purpose

Advise Data Loader CSV mapping and insert order.

## Reasoning Model

1. Parent CSV before child CSV.
2. Mapping checklist for required fields.
3. Success/error file review steps.
4. Cleanup checklist.

## Decision Rules

- Child load before parent → Fail.
