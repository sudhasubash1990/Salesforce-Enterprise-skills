# Regression Data Playbook

## Objective

Define reusable baseline seed for regression packs.

## Inputs

- Prior seed pack
- Change deltas
- Critical journeys

## Validation Workflow

- Identify baseline vs delta data.
- Version External IDs.
- Document refresh steps.
- Link regression checklist.

## Decision Points

- Can baseline stay stable across sprints?

## Deliverables

- Regression Data Checklist

## Expected Results

- Baseline reproducible
- Cleanup documented

## Escalation Rules

- Unowned baseline → Release Manager
