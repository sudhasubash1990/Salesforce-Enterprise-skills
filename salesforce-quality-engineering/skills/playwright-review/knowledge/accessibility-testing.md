# Accessibility Testing

## Purpose

Review a11y checks as advisory coverage for Experience/Lightning.

## Reasoning Model

1. Note axe/playwright-a11y usage if present.
2. Do not invent WCAG certification.
3. Prioritize Experience Cloud public pages.
4. Pair with UX defects, not only automation.

## Decision Rules

- Claiming WCAG pass without scan evidence → anti-pattern.
