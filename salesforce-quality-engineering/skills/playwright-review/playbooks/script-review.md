# Script Review Playbook

## Objective

Review individual Playwright tests and page objects.

## Inputs

- Sample specs
- Page objects
- Assertions

## Validation Workflow

- Review locators/assertions/sync.
- Produce snippet refactors.
- Update Code Quality and Locator sections.

## Decision Points

- Full rewrite requested?

## Deliverables

- Automation Code Review Report sections 4–7

## Expected Results

- Actionable refactors
- Snippets only unless rewrite asked

## Escalation Rules

- Systemic anti-pattern → Automation Lead
