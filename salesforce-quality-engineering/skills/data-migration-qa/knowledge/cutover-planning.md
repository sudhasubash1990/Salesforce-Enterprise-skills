# Cutover Planning

## Purpose

Assess cutover readiness gates and freeze windows.

## Reasoning Model

1. Confirm Migration Scope and mapping gates passed.
2. Define Go / Conditional Go / No-Go criteria.
3. Document communications and ownership.
4. Link Rollback and Hypercare plans.

## Decision Rules

- Open Critical integrity defects → No-Go.
