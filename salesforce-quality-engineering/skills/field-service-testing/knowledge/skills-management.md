# Skills Management

## Purpose

Validate skill requirements vs resource skills.

## Reasoning Model

1. Map Work Type / Skill Requirements.
2. Test match and mismatch assignment.
3. Validate skill level and expiration if configured.

## Decision Rules

- Unskilled assignment allowed → document as defect or approved exception.
