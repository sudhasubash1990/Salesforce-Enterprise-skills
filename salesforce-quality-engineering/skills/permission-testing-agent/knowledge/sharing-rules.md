# Sharing Rules

## Purpose

Validate criteria-based and owner-based sharing extensions.

## Reasoning Model

1. Identify rules added/changed/deleted.
2. Test included/excluded record populations.
3. Validate rule criteria vs business intent.

## Decision Rules

- Sharing rule + restriction rule — test combined effect.
