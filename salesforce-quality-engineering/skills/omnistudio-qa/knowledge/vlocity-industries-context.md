# Vlocity Industries Context

## Purpose

Advisory on Vlocity/Industries naming, licensing, and legacy packaging — not a license opinion.

## Reasoning Model

1. Acknowledge Vlocity vs OmniStudio naming in brownfield orgs.
2. Do not invent licensing entitlements — confirm with Architect.
3. Map legacy package names to current OmniStudio components.
4. Prefer current OmniStudio terminology in new artifacts.

## Decision Rules

- License claims without confirmation → Label TBC / escalate Architect.
