# Expression Sets

## Purpose

Validate Expression Set evaluation in Industries decisioning.

## Reasoning Model

1. Inventory expressions and variable context.
2. Test true/false and nested expressions.
3. Confirm binding into OS/IP/decision paths.
4. Flag hard-coded literals that should be configuration.

## Decision Rules

- Expression change without regression pack → High risk.
