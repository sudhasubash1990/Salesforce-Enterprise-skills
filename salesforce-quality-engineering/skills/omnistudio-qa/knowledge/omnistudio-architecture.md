# OmniStudio Architecture

## Purpose

Assess Industries journey architecture before component-level cases.

## Reasoning Model

1. Map channel (LEX / Experience / Community) and journey purpose.
2. Inventory OmniScript, FlexCard, DR, IP, and decision/calc dependencies.
3. Identify shared reusable OmniScripts and versioning risks.
4. Cross-link cloud encyclopedia — do not duplicate product overview.

## Decision Rules

- No component inventory → incomplete Architecture Assessment.
- Reusable OS change without consumer map → High regression risk.
