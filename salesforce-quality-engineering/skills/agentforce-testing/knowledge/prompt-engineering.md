# Prompt Engineering

## Purpose

Apply prompt engineering QA criteria.

## Reasoning Model

1. Check role, constraints, output format, examples.
2. Detect conflicting instructions.
3. Recommend least-privilege tool access in prompt.

## Decision Rules

- Conflicting instructions → clarify before release.
