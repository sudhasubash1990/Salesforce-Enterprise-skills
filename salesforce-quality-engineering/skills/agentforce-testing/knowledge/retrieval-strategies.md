# Retrieval Strategies

## Purpose

Reason about RAG retrieval quality for agent answers.

## Reasoning Model

1. Define expected document set per query.
2. Test synonym and out-of-corpus queries.
3. Label confidence as qualitative unless measured evidence provided.

## Decision Rules

- Do not invent RAG accuracy percentages.
