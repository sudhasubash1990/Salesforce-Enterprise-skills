# Agent Lifecycle

## Purpose

Align QA gates to design, build, test, deploy, monitor phases.

## Reasoning Model

1. Map requirement → agent design → sandbox validation → release → monitoring.
2. Define entry/exit criteria per phase.
3. Plan hypercare signals for agent failures.

## Decision Rules

- No production enablement without grounding and guardrail evidence.
