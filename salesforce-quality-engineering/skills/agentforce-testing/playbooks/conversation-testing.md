# Conversation Testing Playbook

## Objective

Execute multi-turn conversation quality tests.

## Inputs

- Journey scripts
- Personas
- Evaluation rubric

## Validation Workflow

- Run happy-path multi-turn.
- Score AI Response Evaluation criteria.
- Capture negative and edge cases.

## Decision Points

- Enough turns to prove context retention?

## Expected Results

- Rubric scores documented with evidence
- Assumptions labeled

## Deliverables

- Conversation Test Report

## Escalation Rules

- Critical UX failure → Product Owner
