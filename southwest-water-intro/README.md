# Southwest Water — Nina talking-avatar introduction

Provider-agnostic Node.js pipeline that:

1. Uses the original 16:9 still as the **background** (logos, Alex, Harvey, icons, and labels stay as pixels from that still).
2. Detects/crops **Nina only**.
3. Generates UK English narration.
4. Builds a talking-avatar layer (`IMAGE + AUDIO → talking person`).
5. Composites Nina over the original scene.
6. Adds a very slow camera push and sequential icon highlights.
7. Renders `1920×1080` H.264/AAC MP4.

Alex and Harvey are never sent to the lip-sync engine.

## Installation

```bash
cd southwest-water-intro
cp .env.example .env
npm install
python3 -m pip install -r requirements.txt
```

Required system tools: `ffmpeg`, `ffprobe`, Node 20+, Python 3.10+.

## Source image

Place the official client still at:

```
assets/southwest-water-customer-journey.png
```

If that file is absent, `npm run compose-scene` builds a **branded fixture** from the portrait layers. All titles and journey labels are drawn as SVG text (not regenerated by an image model). Replace the fixture with the real still before a client presentation.

## Provider configuration

| Variable | Purpose |
|---|---|
| `AI_VIDEO_PROVIDER` | `heygen` (preferred), `did`, `replicate`, `local`, or `auto` |
| `AI_VIDEO_API_KEY` / `HEYGEN_API_KEY` | HeyGen |
| `DID_API_KEY` | D-ID talking photo |
| `REPLICATE_API_TOKEN` | SadTalker / Wav2Lip on Replicate |
| `TTS_PROVIDER` | `edge` (default, UK neural, no key), `elevenlabs`, `azure` |
| `EDGE_TTS_VOICE` | default `en-GB-SoniaNeural` |

`.env.example` lists every variable. **Never commit API keys.** Missing cloud credentials print:

```
AI video provider credentials are not configured. Add the required API key to .env.
```

and `auto` then uses the local viseme renderer so the pipeline still produces `IMAGE + AUDIO → talking person` video. HeyGen Avatar IV / D-ID remain the production-quality lip-sync engines.

## Commands

```bash
npm run preview    # ~10–15s: “Hello, and welcome. My name is Nina.”
npm run generate   # full verbatim transcript + talking layer + composite
npm run validate   # face / lip-audio / loudness / 16:9 checks
npm run render     # final MP4
```

Expected output:

```
output/southwest-water-customer-journey-intro.mp4
```

`output/nina-talking.mp4` is the isolated Nina layer.
