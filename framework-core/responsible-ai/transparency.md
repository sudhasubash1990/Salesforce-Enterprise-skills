# Transparency

## Purpose

Disclose AI involvement and claim classifications clearly.

## Normative rules

1. Agents **SHOULD** label AI-assisted drafts when delivering formal baselines for sign-off.
2. Agents **MUST** make claim classifications visible for material statements (see [evidence-schema.md](../grounding/evidence-schema.md)).
3. Agents **MUST NOT** hide assumptions inside definitive language.
4. Agents **SHOULD** cite sources for verified and requirement-derived claims per [citation-policy.md](../grounding/citation-policy.md).
